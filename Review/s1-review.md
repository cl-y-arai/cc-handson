## 2-1. Claude Code

### 指摘: 「エージェント型」が無定義のまま使われている

> Anthropic が提供する **エージェント型コーディングツール**

「エージェント型」とは具体的に何か、他にどんな型があるのかが説明されていない。初心者はこの一文目から意味が取れない。

**改善案（本文への追記例）:**

> Anthropic が提供する **エージェント型コーディングツール**
> （エージェント型 ＝ AIが自分でファイルを読み書き・コマンド実行し、完了まで自律的に作業を進めるタイプ。チャット型と違い、コピペや実行を人間が仲介しない）

**補足（他の「型」との対比）:** AIコーディングツールにはおおむね3つの型がある。

| 型 | 動き方 | 代表例 |
|---|---|---|
| 補完型 | エディタで入力中に続きのコードを提案。人間が主導 | GitHub Copilot（補完機能） |
| チャット型 | 人間がコードを貼り付けて質問し、AIがテキストで回答。適用・実行は人間 | Claude.ai、ChatGPT |
| エージェント型 | AIがファイル操作・コマンド実行まで自分で行い、完了まで回す | **Claude Code**、Cursor Agent など |

なお 2-2 の「Claude.ai との違い」の表がまさに「チャット型 vs エージェント型」の対比になっているため、2-1 に一言定義を足して「詳しくは 2-3 のエージェントループで」と参照を付けると流れが自然になる。

## 3-1. インストール

### 指摘1: ターミナルの開き方の説明がない

インストールコマンドを「どこに」打つのかが資料全体で一度も説明されていない。ターミナルを開いたことがない受講者は最初の1コマンドで止まる。

**改善案:** 3-1 冒頭に OS 別の「ターミナルの開き方」を追加する。

- macOS: Launchpad（または Spotlight で「ターミナル」と検索）→「ターミナル」を開く
- Windows: スタートメニュー →「PowerShell」と入力して開く
- 「以下のコマンドをコピーしてターミナルに貼り付け、Enter」まで明記する

### 指摘2: 「CMD」「PowerShell」が何かの説明がない

Windows のインストール手順に CMD / PowerShell という言葉が出てくるが、初心者はこの2つが何なのか・どちらを使えばいいのかが分からない。

**改善案（一言定義の例）:**

> PowerShell・CMD ＝ どちらも Windows に最初から入っている「コマンドを打つための画面（ターミナル）」。本コースでは PowerShell を推奨。

## 3-2. 起動・終了・再開

### 指摘: 操作の表の一番下「非対話」の意味が分からない

`claude -p "…"` の説明にある「非対話」という言葉が初心者に伝わらない。「返事が返ってこない」と誤解される恐れがある。

**改善案（注意書きの追記例）:**

> **非対話モード（`claude -p "質問"`）** ＝ チャット画面を開かず、ターミナルにその場で答えだけを表示して終了するモード。返事は返ってくるが、会話の続きはできない（一問一答）。結果をファイルに残したり、自動処理に組み込む用途で使う。

- 対話モード ＝ チャット画面が開き、会話のキャッチボールを続けられる（LINE のトークのイメージ）
- 非対話モード ＝ 1回の指示に答えだけ返して即終了（自動販売機のイメージ）

## 3-3. スラッシュコマンド（TIPS: プライバシー設定）

### 指摘: `/privacy-settings` はプランによって表示されない

TIPS の `/privacy-settings` の案内は Pro / Max プラン前提で書かれているが、**Team / Enterprise / API 利用（商用契約）の場合はこのコマンド自体が出てこない**可能性がある。研修を商用プランのアカウントで受講する人が「コマンドが見つからない」と混乱する恐れ。

**検証済みの事実（2026-07-31 時点）:**

- 公式ドキュメント（Data usage）: 学習利用の選択はコンシューマープラン（Free / Pro / Max）のみの設定。商用契約（Team / Enterprise / API）はそもそもデフォルトで学習に使われない
- 実機確認（Claude Code v2.1.218）: `/privacy-settings` コマンドはコンシューマーアカウントでのログイン時のみ有効になる実装

**改善案（注記の追記例）:**

> ※ このコマンドは Pro / Max（個人プラン）でサインインしている場合のみ表示される。Team / Enterprise / API 利用では表示されないが、商用契約ではそもそも会話データがモデルの学習に使われないため設定は不要。表示されない・見つからない場合は、ブラウザから claude.ai/settings/data-privacy-controls でも同じ設定を確認できる。
