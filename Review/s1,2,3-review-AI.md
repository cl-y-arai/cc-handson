## ④ その他・良かった点

### 良かった点（維持すべき工夫）
- 抽象概念に必ず図解が付く。特に「Claude Code = モデル + ハーネス」の図とパーミッション承認フロー図は直感的
- 英語の承認ダイアログを実物例で示し、各選択肢の意味を日本語で解説している
- 「TIPS: スピナー」「TIPS: こんな質問が来たら？」など、初回利用時に戸惑う画面の先回り解説
- 非エンジニア向けの分岐（第1回7章の「普段開発しない方は付録へ」）とコード不要の付録の存在
- /config で日本語UIに切り替える手順を演習1に組み込んでいる
- プライバシー設定（学習オプトアウト）を最初に案内している
- 各章の分数明記と「やってみよう」ボックスでペース配分が分かりやすい

### 優先度の提案
1. **最優先**: agmsg URLの統一（②の詰まりにも直結する実害あり）
2. **高**: ターミナルの開き方／Git・GitHub用語の事前解説の追加（対象受講者がIT知識ゼロなら必須）
3. **中**: 環境準備（GitHubアカウント・gh・bats等）を独立した事前準備章に集約
4. **低**: スクショの撮り直し・モデル表更新・表記ゆれの統一
